## Build it in CapCut (faceless assembly)
1. Black `#0a0b0d` background layer.
2. **Digital-rain overlay**: use CapCut's "code/matrix" effect or a free digital-rain stock clip; set blend mode **Screen** so the black drops out; recolour to lime if possible.
3. Falling **scoreline/year text** in JetBrains Mono; add a **glitch / RGB-split** effect on each entry.
4. Flags resolve in with a glitch-reveal transition; vertical "seam" of code between them.
5. End card: lime text on black, the URL, "No money. Not gambling."
6. **Sound**: a dark cinematic trending audio (synth/braam - Matrix-adjacent). Keep it low under the VO. **Captions on** (most views are muted).
7. No real match footage - the motif is all self-made, which keeps it rights-safe and on-brand.
